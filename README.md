# Museu Y2K — A História dos Cantores Negros

Projeto escolar independente da equipe de Natã, Bryan, Gabriela e João Victor.

## Publicação no GitHub Pages

1. Entre na **sua conta pessoal** do GitHub e crie um novo repositório, por exemplo `museu-y2k-cantores-negros` (não use repositórios de outras pessoas).
2. Envie `index.html` para a **raiz** do repositório.
3. Em **Settings → Pages → Build and deployment**, escolha **Deploy from a branch**, branch `main` e pasta `/(root)`.
4. Abra o endereço HTTPS mostrado em Pages e teste com o celular, em rede móvel.
5. Só depois gere o QR Code para a mostra cultural.

## Checagens necessárias antes da publicação final

- Confirme a imagem de The Notorious B.I.G. no navegador. O link do Wikimedia Commons pode falhar por rede, servidor ou política de acesso. O método garantido é adicionar uma foto autorizada no **Mural** e usar **SALVAR SITE COM AS FOTOS INSERIDAS**; em seguida substitua o `index.html` no GitHub pelo HTML exportado.
- Verifique as licenças de todas as fotografias. A declaração de licença de uma imagem enviada ao Wikimedia Commons pode não comprovar a autorização do fotógrafo original. A fotografia de Kamaitachi no site oficial não tem autorização de redistribuição confirmada.
- Teste os players do YouTube e o QR Code em um endereço HTTPS publicado. Esses serviços exigem internet e podem impor restrições.
- Votos e comentários são locais ao navegador. Eles **não** formam uma votação compartilhada nem mural público.
- A seção Notícias é uma seleção datada, não um feed ao vivo. Atualize os fatos antes da apresentação.
- Teste no celular e, de preferência, em mais de um navegador.

## Estrutura

- `index.html`: site completo com CSS e JavaScript dentro do mesmo arquivo.
- `README.md`: guia e pontos de verificação.
- `.nojekyll`: garante a publicação estática direta do site no GitHub Pages.

> Nenhuma publicação foi feita automaticamente. Esta versão pertence ao projeto escolar de Natã, não aos projetos de Clovis.
