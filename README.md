# Museu Y2K - A Historia dos Cantores Negros

Site escolar independente do projeto de terceiros.

1. Publique index.html na raiz de um repositorio GitHub de sua titularidade.
2. Ative Settings > Pages > Deploy from a branch > main / (root).
3. Para usar uma fotografia escolhida pelo grupo, use o editor de fotos dentro do Mural e exporte o HTML atualizado.
4. Verifique direitos de uso e os creditos de todas as imagens antes da exibicao publica.
5. Reproducao de musicas, fontes e imagens externas depende de acesso a internet.
6. Votos e comentarios sao armazenados localmente, nao compartilhados entre aparelhos.

As biografias oferecem um panorama de pesquisa, com links para referencias; nao pretendem substituir o estudo de fontes originais.
